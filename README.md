# Detecção de Fibrilação Atrial em Sinais Fotopletismográficos utilizando Aprendizado de Máquina Embarcado

Repositório destinado ao projeto de Iniciação Científica (IC) em Engenharia Biomédica e Elétrica pela Universidade Tecnológica Federal do Paraná (UTFPR).

- **Bolsista:** Carlos Eduardo Vaz de Morais Santos
- **Orientador:** Prof. Dr. Fabio Pires Itturriet
- **Instituição:** UTFPR - Campus Curitiba
- **Período:** Outubro/2026 a Setembro/2027

## Objetivo do Projeto
Desenvolver e avaliar um algoritmo de aprendizado de máquina para identificar segmentos de PPG associados à fibrilação atrial e implementá-lo em um microcontrolador da plataforma STM32. 

## Base de Dados
Os dados utilizados pertencem à base **MIMIC-III-Ext-PPG** (via PhysioNet).
